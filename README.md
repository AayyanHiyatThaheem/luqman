## Project Overview

HaulCraft is a sample educational website that introduces beginners to truck dispatching and freight coordination. It contains three linked pages: a home page, a training and packages page, and a student registration page. The website demonstrates semantic HTML, multimedia, tables, forms, and different methods of applying CSS.

## What Is CSS?

CSS stands for Cascading Style Sheets. It controls the appearance and layout of web pages. CSS helps developers apply colors, fonts, spacing, borders, and responsive layouts to make websites readable and attractive.

For example, the rule `p { color: #292c29; }` uses `p` as the selector, `color` as the property, and `#292c29` as the value.

## Three Methods of CSS

Inline CSS is written inside an HTML element's `style` attribute. HaulCraft uses this method on `index.html`. Embedded CSS is written inside a `<style>` element in the document's `<head>` and is used on `information.html`. External CSS is stored in a separate file, `style.css`, which is linked to `registration.html`. External CSS makes styles easier to maintain and reuse.

## CSS Development

CSS1 introduced basic styling features such as fonts, colors, and spacing. CSS2 and CSS 2.1 expanded styling, positioning, media types, and layout capabilities. Modern CSS is developed through separate modules, including Flexbox, Grid, transitions, and media queries.

## Browser Support and HTML Semantics

Browser support matters because different browsers may display some features differently. This website should be tested in Google Chrome and Microsoft Edge. Any observed differences should be recorded after testing.

Semantic HTML gives elements meaningful purposes. For example, `<header>` identifies introductory content. A `<div>` is non-semantic because it does not describe the meaning of its contents.
